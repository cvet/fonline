## Граница

Включено:

- имена файлов .fotxt, синтаксис полей в фигурных скобках, многострочные значения, структурированные ключи и повторяющиеся варианты
- порядок BakeLanguages, инкрементальное повторное запекание, нормализация языков при запекании и имена бинарных выходов
- поля $Text прототипов, наследование, маршрутизация выходных пакетов, декодирование escape-последовательностей и валидация
- клиентские и серверные поверхности script lookup, переключение языка и встроенные цветовые теги рендерера

Исключено:

- языковые приоритеты проекта, владение переводами, терминология и политика готовности релиза
- проектные lexem, подстановка аргументов, синтаксис случайного выбора, форматирование диалогов и обёртки чата
- конкретные имена пакетов кроме пяти пакетов текста прототипов, генерируемых движком
- выбор шрифта, layout, shaping и общий GUI authoring
