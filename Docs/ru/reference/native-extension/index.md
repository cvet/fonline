## Граница

Включено:

- регистрация проектных исходников C++ по ролям через AddEngineSources
- участие зарегистрированных проектных исходников в обработке метаданных и кодогенерации
- необязательные объявления EngineHook, их сигнатуры, владеющие роли, места вызова и сгенерированное поведение по умолчанию
- правила нативного биндинга и пространства имён, необходимые сгенерированным экспортам в скрипты

Исключено:

- проектные реализации расширений, зависимости, настройки, персистентность и релизная политика
- ABI сторонних SDK и проектная упаковка нативных библиотек
- ABI между хостом и средой выполнения клиента и совместимость независимо собранных ревизий движка
- внутреннее устройство нативного скриптового backend, управляемого FO_NATIVE_SCRIPTING
