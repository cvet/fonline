## Приоритет переопределения параметров

1. соответствующая переменная окружения FO_
2. существующее значение кеша CMake или -D
3. значение SetOption, заданное подключающим проектом
4. объявленное значение интерфейса по умолчанию

Побеждает первый определённый источник. Обязательные параметры не имеют значения интерфейса по умолчанию и должны быть заданы проектом.

## Граница

Включено:

- параметры кеша проекта, объявленные на стадии Init
- упорядоченные точки входа стадий генерации проекта и hooks
- выбранные helper-команды подключающего проекта

Исключено из этого среза:

- внутренние helper-функции реализации CMake
- грамматика объявлений пакетов и схемы payload
- интерфейсы командной строки BuildTools
- файлы toolchain и политика платформенных presets

Объявления пакетов и payload описаны в отдельном [справочнике интерфейса пакетов](../packages/index.md). Основная командная строка BuildTools описана в отдельном [справочнике CLI на основе парсера](../buildtools/index.md).
