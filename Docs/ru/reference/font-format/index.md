## Граница ответственности

Включено:

- текстовые дескрипторы .fofnt и их метрики глифов
- дескрипторы binary BMFont v3 .fnt, принимаемые клиентом
- доставка raw-copy и отдельно запечённые изображения шрифтов
- диспетчеризация Game.BindFont, слоты шрифтов, размещение в атласе и startup-fallback
- уменьшение при привязке, преобразование в оттенки серого, создание обводки и эффекты
- флаги TextFormat, перенос, выравнивание, измерение, встроенные цвета и кеширование
- основанная на исходниках диагностика и маршрутизация проверки

Исключено:

- имена шрифтов, каталоги слотов, назначения GUI и типографическая политика подключаемого проекта
- лицензирование шрифтов, права на распространение и приёмка покрытия глифов для конкретных языков
- текстовые и XML-дескрипторы BMFont, которые runtime не разбирает
- семантика конфигурации инструмента авторинга .bmfc
- векторные шрифты и runtime-растеризация TTF/OTF, отсутствующая в клиенте
- проектные пакеты локализации и авторские отображаемые строки
