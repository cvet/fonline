## Граница ответственности

Включено:

- один или несколько якорей ProtoMap со вложенными адресованными по карте секциями Critter и Item
- идентичность карты, ID размещений, ссылки на прототипы, владение и переопределения свойств
- нормализация Mapper, запекание для отдельных сторон и runtime-материализация
- каталоги свойств Map, Critter и Item, которыми владеет движок

Исключено:

- авторские свойства проекта, ID прототипов, каталоги карт и таксономия каталогов
- правила заданий, встреч, баланса, визуальных наборов и дизайна уровней
- runtime-записи сохранения и динамические сущности, созданные после материализации карты
- поиск пути, боевая геометрия, дизайн освещения и зависящие от рендерера рекомендации по композиции

Встраивающие проекты обязаны отдельно документировать добавленные метаданные, прототипы, каталог карт и соглашения по дизайну уровней.
