## Контракт области

Полный текущий инвентарь имеет статус <code>experimental</code> с версии <code>2022.1.0.wip</code>. Объявление закрепляет 2472 стабильных ID хешем SHA-256 <code>75fca70d7e56ae0647d004411014c7b7bd1a2a8422075941895fea957345602b</code>; любое добавление или удаление символа либо изменение стабильного ID останавливает генерацию, пока владелец не проверит и не обновит оба пина.

Полная поверхность native-codegen доступна встраиваемым проектам для оценки, но до появления поддерживаемых веток выпусков остаётся привязанной к ревизии. SymbolCount и InventorySha256 требуют ревью владельца для каждого добавления, удаления или изменения стабильного ID, не позволяя молча расширить это экспериментальное обещание.

## Область

Включено:

- нативные script enum, value/reference types, сущности, свойства, методы и события
- настройки движка, разобранные из `ExportSettings`
- нативные правила миграции
- заданные в исходниках API-контракты, разобранные из `ApiContract`

Исключено из текущей модели:

- проектная script metadata, включая remote calls
- options CMake и helpers стадий
- интерфейсы командной строки BuildTools
- схемы пакетов и детали ABI нативных расширений

Project-facing объявления CMake намеренно находятся вне этой модели; используйте отдельный [сгенерированный справочник project interface CMake](../cmake/index.md).

Основная командная строка BuildTools также находится вне этой модели; используйте отдельный [справочник CLI на основе parser](../buildtools/index.md).

Объявления пакетов и payload используют отдельный контракт, потребляемый runtime; смотрите [справочник интерфейса пакетов](../packages/index.md).

Ссылки на исходники следуют ветке `master` репозитория. Путь и строка в каноническом JSON являются сгенерированной provenance-записью; ссылки с точной привязкой к ревизии остаются частью roadmap публикации.
