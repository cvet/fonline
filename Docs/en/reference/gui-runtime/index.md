# Generated GUI Runtime Reference (Retired)

The Engine-owned AngelScript GUI library and this generated reference were retired when high-level script libraries moved to embedding projects. Use the [GUI integration boundary](../../how-to/runtime/gui.md); the project that owns a GUI implementation must document its current types and behavior.
