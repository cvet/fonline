# Contributing

Keep the example smaller than the production pattern it teaches. Changes must preserve the exact Engine pin, pass the pinned and current-Engine lanes, update the relevant tutorial or source link, and include provenance for every new asset.

Generated files must be changed through their owning generator. Reusable Engine defects belong in `cvet/fonline`; example-specific code, presentation, and teaching defects belong here. Do not copy Last Frontier or TLA content, credentials, CI policy, or project-only helpers.

Pull requests must explain the user-visible teaching outcome, validation performed, compatibility impact, and any license or provenance change.
